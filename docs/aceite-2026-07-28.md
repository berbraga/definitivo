# Verificação dos critérios de aceite

Executado em 2026-07-30. Atualizado em 2026-07-30 para **fontes v2**
(`mercadolivre`, `trocafy`, `rede_cell_store`, `celular_seminovo_rede`,
`cellularstore`). Os critérios 2–5 da rodada v1 usavam `olx`, `enjoei` e
`mercadolivre`; a rodada v2 ainda depende de `ANTHROPIC_API_KEY` válida.

| # | Critério | Resultado | Evidência |
|---|---|---|---|
| 1 | dry-run mostra plano e custo sem gastar | PASSOU (v2) | 10 modelos × 5 fontes = 50 pares, 100 chamadas, ~US$ 6,50 |
| 2 | 8 de 10 modelos com status=ok e n>=5 | BLOQUEADO | API key inválida (`401`) na rodada real |
| 3 | 10 anúncios amostrados: zero acessório, zero modelo trocado, zero parcelado | BLOQUEADO | Sem relatório de coleta real v2 |
| 4 | link_minimo e link_maximo correspondem ao preço e ao modelo | BLOQUEADO | Sem relatório de coleta real v2 |
| 5 | --retomar não dispara busca nova | BLOQUEADO | Cache do dia não populado (coleta falhou) |
| 6 | ruff, mypy e pytest verdes | PASSOU | 271 testes, zero erros de lint ou tipo |
| 7 | Android com --somente-ativos resulta em 285 modelos | PASSOU | `Modelos a pesquisar: 285` no dry-run |
| 8 | hash SHA-256 da entrada inalterado | PASSOU | `sha256sum -c` OK após tentativa de rodada |

## Comandos executados

```bash
# Critério 1 (fontes v2 — default em fontes.yaml)
uv run renov-market-scan run --input Template-iPhone.xlsx --limite 10 --dry-run
# → 50 pares (modelo x fonte), 100 chamadas, US$ 6,50

# Critério 7
uv run renov-market-scan run --input RS_Maio_Androids_2026.xlsx --dry-run

# Critério 6
uv run ruff check . && uv run mypy renov_market_scan && uv run pytest

# Critério 2 (falhou na API — v1)
printf 'y\n' | uv run renov-market-scan run \
  --input Template-iPhone.xlsx --output out/ \
  --fontes olx,enjoei,mercadolivre --limite 10 --concorrencia 4
# → AuthenticationError: API key is invalid

# Rodada v2 planejada (após corrigir .env)
printf 'y\n' | uv run renov-market-scan run \
  --input Template-iPhone.xlsx --output out/ \
  --cache .cache/scan-v2.sqlite \
  --limite 3 --concorrencia 4

# Spike fontes v2
uv run python spikes/source_survey_v2.py
# → AuthenticationError: API key is invalid

# Critério 8
sha256sum Template-iPhone.xlsx  # 1c7ef1c5e0bd9a68583bbc544baa2040e807b42991a211b44821d769ba8d8084
sha256sum -c /tmp/hash-antes.txt  # OK
```

## Observações

- O dry-run v2 de 10 modelos × 5 fontes estima **US$ 6,50** (100 chamadas à API).
- O dry-run v1 (3 fontes) estimava **US$ 3,90** para 10 modelos — custo +67% por modelo.
- O dry-run do Android completo (285 modelos × 5 fontes) estima **~US$ 185** —
  usar `--limite` em produção até validar a qualidade das regras.
- Após corrigir a `ANTHROPIC_API_KEY` no `.env`, repetir spike v2, rodada real
  `--limite 3` e os critérios 2–5.
